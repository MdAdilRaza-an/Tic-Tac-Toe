# Tic Tac Toe Game

A simple two-player Tic Tac Toe desktop game developed using Java Swing and AWT.

## Features

- 3×3 game board
- Two-player X and O gameplay
- Winner detection
- Draw detection
- Simple graphical interface

## Technologies

- Java
- Java Swing
- AWT
- OOP Concepts

## How to Run

1. Clone the repository
2. Open the project in IntelliJ IDEA / Eclipse / VS Code
3. Run App.java
